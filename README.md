# 32-bit Single-Cycle MIPS Processor

A 32-bit single-cycle MIPS processor implemented in Verilog HDL, with modular RTL blocks for the program counter, instruction memory, register file, control unit, ALU, and data memory.

The project includes individual module-level testbenches and a top-level processor testbench for simulation and waveform-based verification.

## Overview

This project implements a simplified 32-bit MIPS processor using a single-cycle datapath.

Each instruction is processed through the complete datapath within a single clock cycle. The processor is built from separate RTL modules that are integrated through the top-level `mips_core` module.

The implementation covers:

- Program counter management
- Instruction fetching
- Instruction decoding
- Register file operations
- ALU operations
- Data memory access
- Branch control
- Jump control
- Register write-back
- Module-level simulation
- Processor-level simulation
- VCD waveform generation

## Datapath

The processor follows the standard stages of a simplified single-cycle datapath:

```text
Instruction Fetch
        |
        v
Instruction Decode
        |
        v
Register Read
        |
        v
Execute / Address Calculation
        |
        v
Memory Access
        |
        v
Write Back
```

Branch and jump instructions modify the next program-counter value through the PC control logic.

## RTL Modules

### Program Counter

The `pc` module stores the current 32-bit program counter.

It:

- Updates on the rising edge of the clock
- Supports asynchronous reset
- Loads the calculated next PC value

```text
Reset
  |
  v
PC = 0
  |
  v
PC <- PC_next
```

### Instruction Memory

The `instruction_mem` module implements a 64-word instruction memory.

Instructions are accessed using word-aligned addressing:

```text
addr[7:2]
```

The current instruction memory contains a demonstration program used by the processor-level simulation.

### Register File

The `register_file` module implements:

- 32 registers
- 32-bit register width
- Two asynchronous read ports
- One synchronous write port

Register `$0` is hardwired to zero by preventing writes to register zero and returning zero whenever it is read.

### Control Unit

The `control_unit` module decodes the instruction opcode and function field and generates the control signals required by the datapath.

The control signals include:

```text
reg_dst
reg_write
alu_src
mem_read
mem_write
mem_to_reg
branch
jump
alu_ctrl
```

The control unit distinguishes between R-type, load/store, branch, immediate, and jump instructions.

### ALU

The ALU performs the following operations:

| ALU Control | Operation |
|---|---|
| `000` | AND |
| `001` | OR |
| `010` | ADD |
| `110` | SUB |
| `111` | SLT |

The ALU also generates a `zero` flag.

The zero flag is used by the branch logic for `BEQ` instructions.

### Data Memory

The `data_mem` module implements a 64-word × 32-bit memory.

It provides:

- Asynchronous read
- Synchronous write
- Word-aligned addressing through `addr[7:2]`

Memory access is controlled using the `mem_read` and `mem_write` signals generated by the control unit.

## Supported Instructions

The processor implements a subset of the MIPS instruction set.

### R-Type Instructions

| Instruction | Function |
|---|---|
| `ADD` | Addition |
| `SUB` | Subtraction |
| `AND` | Bitwise AND |
| `OR` | Bitwise OR |
| `SLT` | Set on Less Than |

### I-Type Instructions

| Instruction | Function |
|---|---|
| `LW` | Load word |
| `SW` | Store word |
| `BEQ` | Branch if equal |
| `ADDI` | Add immediate |

### J-Type Instructions

| Instruction | Function |
|---|---|
| `J` | Jump |

## Instruction Execution

The current instruction memory contains a small demonstration program:

```text
ADDI  $1, $0, 5
ADDI  $2, $0, 10
ADD   $3, $1, $2
BEQ   $3, $0, 1
SUB   $4, $3, $2
J     5
```

The intended execution is:

```text
$1 = 5
$2 = 10

$3 = $1 + $2
   = 15

BEQ checks:
$3 == $0
15 == 0
Branch not taken

$4 = $3 - $2
   = 5

Jump to instruction 5
```

This program exercises:

- Immediate arithmetic
- Register-to-register arithmetic
- Register file read/write operations
- Branch evaluation
- Jump control

## Control Flow

The next program-counter value is selected according to the instruction type.

```text
                    +-------------+
                    |   PC + 4    |
                    +------+------+
                           |
                           v
                    +-------------+
                    | Branch Logic|
                    +------+------+
                           |
                           v
                    +-------------+
                    | Jump Logic  |
                    +------+------+
                           |
                           v
                        PC_next
```

The implemented priority is:

```text
Jump
  |
  +-- if jump = 1
  |
  v
Jump Address

Otherwise

Branch AND Zero
  |
  +-- if branch = 1 and zero = 1
  |
  v
Branch Target

Otherwise

PC + 4
```

## Verification

The repository contains individual testbenches for the major RTL modules.

### Module-Level Testbenches

```text
alu_tb
controlunit_tb
data_mem_tb
instruction_mem_tb
pc_tb
reg_file_tb
```

These testbenches provide isolated simulation of the individual processor components.

### Processor-Level Testbench

The `top_tb.v` testbench instantiates the complete `mips_core`.

The simulation:

1. Generates the processor clock
2. Applies reset
3. Releases reset
4. Allows the processor to execute the program stored in instruction memory
5. Generates a VCD waveform
6. Ends the simulation

The testbench uses:

```text
dump.vcd
```

for waveform inspection.

## Design Characteristics

The processor is implemented as a single-cycle architecture.

The main characteristics of the design are:

- 32-bit datapath
- 32-bit program counter
- 32 × 32-bit register file
- 64-word instruction memory
- 64-word data memory
- Combinational control logic
- Combinational ALU
- Synchronous register writes
- Synchronous data-memory writes
- Asynchronous register reads
- Asynchronous data-memory reads
- Branch and jump support

## Scope

This project is an educational RTL implementation of a simplified single-cycle MIPS processor.

It is intended to demonstrate processor architecture and RTL design concepts rather than implement a complete production MIPS processor.

The implemented instruction set is limited to the instructions listed in the Supported Instructions section.
